## 사용법

1. [문제 목록](https://4yf494v9nr-create.github.io/geometry-motion-archive1/)에서 학년도/시험/번호를 검색
2. 오른쪽 **3D 단계별 풀이 열기**를 선택
3. 손가락 또는 마우스로 입체도형 회전, 축 표시, 단계별 재생
4. 지원 브라우저에서는 풀이 장면 WebM/MP4 영상 녹화·저장

문항 목록은 `data/problems.json`에, 3D 해설은 `data/lessons.json` 및 `data/lessons-extra-1.json`, `data/lessons-extra-2.json`, `data/lessons-extra-3.json`에 저장되어 있습니다. `viewer.js`가 파일을 병합하여 불러옵니다.

## 배포

GitHub Pages가 `main` 브랜치의 `/(root)`를 자동 배포합니다. Render는 결제 정보 요구로 사용하지 않습니다.

## 원문과 저작권

이 비공식 학습 사이트의 출처는 한국교육과정평가원 공개 평가원 문제지 및 이용자가 제공한 추출 PDF입니다. 원문 PDF/기출 문항의 저작권은 한국교육과정평가원에 있습니다. 3D 모델의 도면은 문제 조건을 재구성한 것이며 원문의 그림과 완전히 같을 필요는 없습니다. 풀이에 오류가 있다면 GitHub Issue로 신고할 수 있습니다.

## 평가원·교육청·사설 출처 등록 규칙

목록은 `data/problems.json`의 각 문항에 다음 필드를 사용합니다.

```json
{
  "id": "edu-2026-10-30",
  "sourceType": "교육청",
  "sourceName": "서울특별시교육청",
  "year": 2026,
  "exam": "10월 전국연합학력평가",
  "subject": "기하",
  "number": 30,
  "title": "문제의 주요 개념",
  "description": "문항 설명",
  "answer": null,
  "status": "pending"
}
```

사설 시험은 `sourceType: "사설"`, `sourceName: "출판사 또는 모의고사 브랜드"`, `exam: "시험 이름·회차"`로 등록합니다. 출처와 시험명이 달라도 동일하게 검색/분류할 수 있습니다.

`status: "solved"`로 등록하려면 `data/lessons.json` 또는 `data/lessons-extra-*.json`에 같은 `id`로 3D 좌표·단계별 풀이가 있어야 합니다. 기존 16문항은 모두 `sourceType: "평가원"`으로 분류했습니다.

**주의:** 사설 및 교육청 문제 원문을 공개 사이트에 게시할 경우 각 저작권자의 이용 허락 또는 허용 범위를 확인해야 합니다.

## 보조선 작도와 이면각 시각화 (2026-10-26)

기존 단계별 풀이 뒤에 **보조선 작도 단계**를 추가했습니다. 현재 3D 풀이가 공개된 17문항에 대해 총 43개 작도 단계가 등록되어 있습니다.

- 기존 풀이 단계에서 **보조선 작도 바로 보기**를 누르면 해당 문항의 첫 작도 단계로 이동합니다.
- 이면각 문항은 **교선 확인 → 두 평면 위에서 교선에 수직인 보조선 작도 → 각도 호와 직각 표시 → 길이·넓이 계산** 순서로 설명합니다.
- 수선의 발, 높이, 대칭축, 평면 법선은 별도 색상의 점·선·화살표로 표시하며, 작도 단계별로 누적됩니다.
- **원래 도형 함께 보기** 체크박스에서 원본 도형과 작도선의 겹침을 조절할 수 있습니다.
- 주요 작도 좌표와 설명은 `data/constructions.json`에 저장됩니다. `viewer.js`는 해당 파일을 불러와 원래 `lesson.steps`에 연결합니다.

각도 표시와 직각 표식은 좌표로 계산된 예시 모델을 기준으로 합니다. 사설 및 평가원 원본 문제 그림과 동일한 투영을 보장하지 않습니다.

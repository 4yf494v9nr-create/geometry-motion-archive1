# GEOMETRY MOTION — 수능 기하 공간도형 3D 풀이 아카이브

**사이트:** https://4yf494v9nr-create.github.io/geometry-motion-archive1/

학년도 → 시험 → 문항 번호를 선택해 평가원 기하 공간도형을 회전 가능한 3D 도형과 함께 단계별로 풀어 볼 수 있습니다. 공개된 해설은 저장된 JSON/JavaScript 파일만 읽어 실행하므로 열람 시 OpenAI API 호출이 없습니다.

## 업데이트: 2026-10-24

- 전체 선별 문항: **16문항**
- **3D 풀이 공개: 15문항** (기존 3개 + 이번에 추가된 12개)
- 검산·모델링 추가 문항: **2022학년도 9월 29번, 2022학년도 수능 29·30번, 2023학년도 수능 30번, 2024학년도 9월 28번, 2024학년도 수능 28번, 2025학년도 9월 27번, 2025학년도 수능 27·28번, 2026학년도 9월 28번, 2026학년도 수능 27·28번**
- 풀이 준비 중(이전 목록): **2023학년도 수능 27번** — 이번 업로드된 기하 29·30번 추출 파일에는 포함되지 않아 그대로 보류
- 이번 PDF에서 기존 풀이와 중복되어 생략한 문항: **2025학년도 9월 28번, 2027학년도 9월 28번**
- 전체 3D 풀이 단계: **90단계**

## 사용법

1. [문제 목록](https://4yf494v9nr-create.github.io/geometry-motion-archive1/)에서 학년도/시험/번호를 검색
2. 오른쪽 **3D 단계별 풀이 열기**를 선택
3. 손가락 또는 마우스로 입체도형 회전, 축 표시, 단계별 재생
4. 지원 브라우저에서는 풀이 장면 WebM/MP4 영상 녹화·저장

문항 목록은 `data/problems.json`에, 3D 해설은 `data/lessons.json` 및 `data/lessons-extra-1.json`, `data/lessons-extra-2.json`, `data/lessons-extra-3.json`에 저장되어 있습니다. `viewer.js`가 파일을 병합하여 불러옵니다.

## 배포

GitHub Pages가 `main` 브랜치의 `/(root)`를 자동 배포합니다. Render는 결제 정보 요구로 사용하지 않습니다.

## 원문과 저작권

이 비공식 학습 사이트의 출처는 한국교육과정평가원 공개 평가원 문제지 및 이용자가 제공한 추출 PDF입니다. 원문 PDF/기출 문항의 저작권은 한국교육과정평가원에 있습니다. 3D 모델의 도면은 문제 조건을 재구성한 것이며 원문의 그림과 완전히 같을 필요는 없습니다. 풀이에 오류가 있다면 GitHub Issue로 신고할 수 있습니다.
